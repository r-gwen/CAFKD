# CAFKD

This repository accompanies our paper **Cross-Modal Adaptive Feedback Knowledge Distillation for Enhanced sEMG-Based Semantic Recognition**.

The code is currently being organized. The complete code will be released after the paper is officially published.

## Dataset

AVE-Speech is a Mandarin speech dataset containing synchronized audio, lip video, and six-channel surface electromyography (sEMG) recordings from 100 participants. Each participant repeated a corpus of 100 sentences ten times.

[Download AVE-Speech](https://huggingface.co/datasets/MML-Group/AVE-Speech)
